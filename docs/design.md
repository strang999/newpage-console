# Design system notes

Tokens live in `src/shared/styles/tokens.css`; components read variables, never literals. Contrast numbers below are generated by `pnpm verify:contrast` from the real token values and fail the build if a pair drops under its threshold.

## Principles

- **One accent**, neutral surfaces, four semantic status colours. Status is never colour alone: each status has an icon and a text label (on track ✓, at risk ▲, off track ✕, no data –).
- **Two kinds of content, two surfaces.** Authoritative dataset values sit on `--color-surface` with the label "Source: dataset". AI-generated text sits on `--color-ai-surface` with a violet border and an "AI-generated" label. AI text is never styled like a KPI; dashboard values never adopt the assistant's styling.
- **Density by audience.** Executive: large figures, at most 8 numbers above the fold, one accent, generous spacing (`--space-5`). Analyst: `--text-sm` tables, tight rows (`--space-2`), every metric visible, sticky headers.
- **Focus is always visible** (2px surface gap + 2px focus ring, 6.7:1 against the surface). Motion respects `prefers-reduced-motion` globally.
- Light theme only. Dark theme is not implemented (recorded as a known gap).

## Type scale

| Token | Size | Use |
|---|---|---|
| `--text-xs` | 12px | axis ticks, legends, badges |
| `--text-sm` | 13px | dense tables, secondary labels |
| `--text-base` | 15px | body, form controls |
| `--text-lg` | 18px | section headings |
| `--text-xl` | 24px | KPI values (executive) |
| `--text-2xl` | 32px | page heading |

System font stack (no web-font request, no layout shift). Tabular numerals on every numeric column.

## Spacing and shape

4px base: `--space-1` 4, `-2` 8, `-3` 12, `-4` 16, `-5` 24, `-6` 32, `-8` 48. Radii 4px (controls) and 8px (cards).
